# 📱 AI学習クイズBot (LINE × GAS × OpenAI)

学習ログを自動でクイズ化し、LINEで復習できる効率化ツールです。

## 🌟 概要
日々の学習内容（スプレッドシートに蓄積されたログ）から、OpenAI APIが自動で4択クイズを生成し、LINE Messaging APIを通じて出題します。
「忙しい中小企業でも、スキマ時間で効率よくスキルアップできる環境」を想定して開発しました。

## 🛠 使用技術
- **Google Apps Script (GAS)**: サーバーレスでのシステム構築
- **OpenAI API (gpt-4o-mini)**: 学習ログに基づいたクイズの動的生成
- **LINE Messaging API**: ユーザーインターフェースとしての活用
- **Google Sheets**: 学習ログのデータベース

## ✨ こだわったポイント
- **即時性**: LINEで「クイズ」と送るだけで、AIが瞬時に問題を作成。
- **効率化の視点**: 復習準備の手間をゼロにし、年間約40万円相当（自社試算）の学習コスト削減を実現。
- **拡張性**: 今後は「正解判定機能」や「忘却曲線に基づいた定期配信」の実装を予定しています。

## 🚀 使い方
1. LINE公式アカウントを友だち追加。
2. トーク画面で「クイズ」と送信。
3. AIが生成した問題に回答（現在は問題と答えがセットで表示されます）。
